Linux Basic Commands

pwd

Purpose:
Show the current working directory.

Example:
pwd

Output:
/root/OSCP-Journey

Use Case:
Used to verify your current location before working with files.

---

ls

Purpose:
List files and directories.

Example:
ls

Useful Options:

ls -l
Long listing format

ls -a
Show hidden files

ls -la
Long listing + hidden files

Use Case:
Used to inspect directory contents.

---

cd

Purpose:
Change the current directory.

Examples:

cd /etc

cd ~

Go to home directory

cd ..

Go to parent directory

Use Case:
Used for filesystem navigation.
