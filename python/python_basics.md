Python Basics

What is Python?

Python is a simple and powerful programming language.

Purpose:
Used for automation, scripting, data processing, and security tools.

Example:

print("Hello World")

Output:

Hello World

---

Variables

Purpose:
Store data in memory.

Example:

name = "Achu"
age = 25

---

Data Types

String

name = "Achu"

Integer

age = 25

Float

price = 99.99

Boolean

is_admin = True

---

Input

Example:

name = input("Enter your name: ")
print(name)

---

If Statement

Example:

age = 18

if age >= 18:
    print("Adult")

---

Loops

For Loop

for i in range(5):
    print(i)

While Loop

count = 0

while count < 5:
    print(count)
    count += 1

---

Functions

Example:

def greet():
    print("Hello")

greet()

---

File Reading

Example:

with open("file.txt", "r") as f:
    print(f.read())
