Networking Fundamentals

IP Address

Definition:
An IP address is a unique number assigned to a device on a network.

Purpose:
Used to identify and communicate with devices.

Example:
192.168.1.10

Real World Use:
Your phone, laptop, and router all have IP addresses.

---

Subnet Mask

Definition:
A subnet mask helps determine which part of an IP address belongs to the network and which part belongs to the device.

Purpose:
Used to organize and manage networks.

Example:
255.255.255.0

Real World Use:
Helps devices know if another device is on the same network.

---

Default Gateway

Definition:
The default gateway is the device that connects your local network to other networks.

Purpose:
Used to send traffic outside the local network.

Example:
192.168.1.1

Real World Use:
Usually your router is the default gateway.

---

DNS

Definition:
DNS (Domain Name System) converts domain names into IP addresses.

Purpose:
Allows users to access websites using names instead of IP addresses.

Example:
google.com → 142.250.x.x

Real World Use:
When you open a website, DNS finds the correct IP address.

---

TCP

Definition:
TCP (Transmission Control Protocol) is a reliable communication protocol.

Purpose:
Ensures data arrives correctly and in order.

Example:
Websites, email, file transfers.

Real World Use:
Used when data accuracy is important.

---

UDP

Definition:
UDP (User Datagram Protocol) is a fast communication protocol.

Purpose:
Sends data without checking if everything arrives correctly.

Example:
Video calls, online games, streaming.

Real World Use:
Used when speed is more important than reliability.

---

HTTP

Definition:
HTTP (HyperText Transfer Protocol) is used to transfer web pages.

Purpose:
Allows browsers and websites to communicate.

Example:
http://example.com

Real World Use:
Used when visiting websites.

---

HTTPS

Definition:
HTTPS is the secure version of HTTP.

Purpose:
Encrypts data between the browser and website.

Example:
https://example.com

Real World Use:
Used for online banking, shopping, and secure websites.

---

Quick Summary

Subnet Mask

Default Gateway

DNS

TCP

UDP

HTTP
