Web Fundamentals

What is the Web?

The web is a system that allows users to access websites using a browser.

Examples:

- Google
- YouTube
- GitHub

Purpose:
Provides information and services over the internet.

---

HTTP

Definition:
HTTP (HyperText Transfer Protocol) is used for communication between a browser and a web server.

Purpose:
Transfers web pages and data.

Example:
http://example.com

Real World Use:
When you open a website, your browser sends an HTTP request.

---

HTTPS

Definition:
HTTPS is the secure version of HTTP.

Purpose:
Encrypts data between the browser and the server.

Example:
https://github.com

Real World Use:
Used for banking, shopping, and secure websites.

---

URL

Definition:
A URL (Uniform Resource Locator) is the address of a web resource.

Example:
https://example.com/login

Parts:

- Protocol: https
- Domain: example.com
- Path: /login

Purpose:
Helps browsers locate resources.

---

HTTP Request

Definition:
A request sent from a client to a server.

Purpose:
Asks the server for information or actions.

Example:

GET /index.html HTTP/1.1

Real World Use:
Loading a webpage.

---

HTTP Response

Definition:
A response sent by the server to the client.

Purpose:
Returns data or status information.

Example:

HTTP/1.1 200 OK

Real World Use:
Displays a webpage in the browser.

---

GET Method

Definition:
Used to request data from a server.

Purpose:
Retrieve information.

Example:
https://example.com/search?q=test

Real World Use:
Search engines and web pages.

---

POST Method

Definition:
Used to send data to a server.

Purpose:
Submit information.

Example:
Login forms and registration forms.

Real World Use:
Sending usernames and passwords.

---

Headers

Definition:
Additional information sent with requests and responses.

Examples:

- User-Agent
- Host
- Cookie
- Content-Type

Purpose:
Provides details about the communication.

---

Cookies

Definition:
Small pieces of data stored in the browser.

Purpose:
Remember user information.

Example:
Session ID

Real World Use:
Keeping users logged in.

---

Sessions

Definition:
A way for websites to track users after login.

Purpose:
Maintain user state.

Example:
User logs in and stays authenticated.

Real World Use:
Online banking and social media.

---

Status Codes

200 OK
Request successful.

301 Moved Permanently
Resource moved.

403 Forbidden
Access denied.

404 Not Found
Resource not found.

500 Internal Server Error
Server-side problem.

---

DNS

Definition:
Domain Name System converts domain names into IP addresses.

Example:
google.com → IP address

Purpose:
Allows users to access websites using names instead of IP addresses.

---

URL

POST
